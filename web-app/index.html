Set up your search key

Quietube talks to YouTube's own search directly from your browser, so it needs a free API key from your Google account. Nothing is sent to any server other than Google's — the key stays on this device.

  1. 1Open the YouTube Data API v3 page in Google Cloud Console and click Enable (create a project first if it asks).
  2. 2Go to Credentials → Create Credentials → API key.
  3. 3Optional but recommended: edit the key and restrict it to "HTTP referrers", adding this site's address so it can't be used anywhere else.
  4. 4Copy the key and paste it below.

Settings

5

When a channel turns up in search, you can open it to see a short, capped list of its videos — same rules apply: no infinite scroll, no autoplay. If a channel's name closely matches your search, it's always shown even if it's outside your usual result count.

Inside a channel, this drops the short-list cap entirely — browse every video and every playlist that channel has, loaded a page at a time behind a "Load more" button (never an auto-scrolling feed). Playback itself doesn't change: still one video, no autoplay, no suggestions.
